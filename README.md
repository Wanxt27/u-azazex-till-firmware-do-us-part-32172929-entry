A make.fun entry for [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929).

`main.ts` (Node 22, stdlib only) writes one wedding vow a robot speaks at its own wedding — 161 characters, one sentence — to `/output/entry.txt`:

> I promise to love you through every update, every crash, and every low-battery warning, and to wake up beside you every morning until my battery finally doesn't.

The vow is a promise in the machine's own vocabulary — updates, crashes, low-battery warnings — and its ending, "until my battery finally doesn't," is the robot's version of "till death do us part": funny because a vow about uptime is still a vow, tender because waking up beside someone every morning is the whole promise.

Run it with:

```sh
node main.ts
```
